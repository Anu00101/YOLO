# YOLOv8 Object Detection with OpenCV and Ultralytics

A lightweight starter project for real-time object detection using Ultralytics YOLOv8 and OpenCV.

## 📂 Repository Structure

```text
.
├── 1.yolo_check.py       # Verifies Ultralytics & PyTorch installation
├── 2.yolov8_basics.py    # Basic YOLOv8 inference on single images
├── 3.yolov8_n_opencv.py  # Real-time object detection on video/webcam using OpenCV
├── coco.txt              # Standard 80-class COCO label map
└── weights/              # Pretrained model weights (e.g., yolov8n.pt)
